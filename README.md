# 나 혼자만 전설의 용사 v6

## v6 수정 사항
- 능력치 데이터가 누락되거나 배열이 아닌 경우 기본 직업 능력치로 보정하여 undefined 표시 방지
- 모바일 능력치 카드가 화면 밖으로 넘치지 않도록 반응형 그리드 수정
- 아카데미 중퇴는 제거하지 않고, 랜덤 이벤트와 별개로 이벤트 화면 하단에 상시 표시
- 아카데미 랜덤 이벤트에서 중퇴 이벤트를 제외하되 개인 활동, 대회, 교우 관계, 교수 특별 지도, 장학금 이벤트 유지
- 기존 성공 확률 및 수업 성공률 90% / 실패율 10% 유지

## 배포
GitHub 저장소의 index.html, style.css, app.js를 교체하고 커밋한 뒤 Pages 배포를 확인하세요.


## v7 변경 사항
- 아카데미 인연 이벤트를 친구·경쟁자 이벤트와 별도 이벤트로 분리해 랜덤 목록에 포함
- 교수 특별 지도에서 현재 직업은 변경 선택지에서 제외
- 대회 선택지에 성공 보상과 실패 페널티 표시 및 적용
- 모험가 승급 명성 기준을 50 단위(0/50/100/150/200)로 변경
