# 나 혼자만 전설의 용사 (ELDORIA) v4

## 포함된 파일
- `index.html`
- `style.css`
- `app.js`

## 이번 업데이트
- 시작 직업 6종: 전사, 마법사, 도적, 약초사, 사냥꾼, 귀족
- 모험가 연간 활동 3회
- 의뢰 4종 및 하급/상급 난이도, 연간 2개 제시
- 모험가 등급 5단계와 명성 승급 기준
- 승급 시험(활동 2회 소모)
- 탐험 장소 13곳, 장소별 보상/실패 페널티
- 직업/능력치 기반 탐험 장소 등장 가중치
- 생명 물약 3%, 장비 발견 70%, 희귀도별 장비 확률
- 장비 자동 적용, 최대 6개, 가방이 가득 찼을 때 교체 선택
- 체력 100, 의뢰/탐험 실패 페널티와 인생 종료 처리

## 임시 밸런스 수치
사용자가 아직 세부 수치를 정하지 않은 의뢰 성공률/보상, 승급 시험 비용과 실패 명성 감소, 수련/휴식 효과, 특수 전설 장비 효과 등은 플레이가 가능하도록 임시 수치로 설정했습니다. 이후 테스트하며 조정하면 됩니다.

## 업데이트 방법 (모바일)
1. 압축을 풀어 `index.html`, `style.css`, `app.js` 세 파일을 확인합니다.
2. GitHub 저장소에서 기존 세 파일을 각각 새 파일 내용으로 교체합니다.
3. Commit changes를 누릅니다.
4. Cloudflare Pages 배포가 완료되면 사이트를 새로고침합니다.

`README.md`는 안내용 파일이며 사이트 실행에는 필수가 아닙니다.
