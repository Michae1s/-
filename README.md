# 나 혼자만 전설의 용사 v5

## 적용 방법
1. `index.html`, `style.css`, `app.js`를 기존 저장소 파일과 교체합니다.
2. GitHub에서 변경 사항을 Commit합니다.
3. Cloudflare Pages 배포 완료 후 사이트를 새로고침합니다.

## v5 변경 사항
- 직접 입력을 요구하는 `prompt()` 제거
- 자유 연구는 능력치 선택지로 변경
- 교수 특별 지도에서 직업을 버튼으로 선택
- 아카데미 중퇴 버튼을 아카데미 화면 하단에 상시 표시하고 랜덤 이벤트에서 제거
- 아카데미 수업 성공 확률 90%, 실패 확률 10%
- 수업 선택지에 성공 확률과 성공 시 상승 능력치 표시
- 의뢰, 탐험, 승급 시험, 장학금 선택지에 성공 확률 표시
