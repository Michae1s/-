# 나 혼자만 전설의 용사 — ELDORIA

모바일 브라우저에서도 실행할 수 있는 정적 웹사이트입니다.

## 포함된 기능
- 10개 직업 선택 및 시작 능력치 무작위 변동(-3~+3, 변동 합계 0)
- 아카데미 입학 여부 선택
- 룸메이트 후보 3명 중 선택
- 15~19세 아카데미 수업 및 이벤트
- 수업별 5% 부정적 사건
- 개인 활동, 대회, 교우 관계, 중퇴, 교수 특별 지도, 장학금 이벤트
- 20세 자동 졸업 후 교수 또는 초급 모험가 선택
- 교수 은퇴 시 초급 모험가로 전환
- 50세 또는 모험가 은퇴 시 인생 종료 및 새 인생 시작

## 실행
`index.html` 파일을 브라우저에서 열면 됩니다. 서버가 필요 없는 HTML/CSS/JavaScript 정적 사이트입니다.

## 배포
Cloudflare Pages에서 Framework preset을 `None`으로 설정하고 Build command는 비워 둡니다. Build output directory는 프로젝트 파일이 있는 루트 디렉터리(`.`)로 설정합니다.

## 참고
아직 1차 통합 버전입니다. 일반 랜덤 이벤트, 교수 생활 성장 규칙, 모험가 생활 이벤트는 플레이가 이어지도록 기본 규칙을 임시로 넣었습니다. 이후 사용자와 함께 확정한 규칙에 맞춰 조정할 수 있습니다.
