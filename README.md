# 나 혼자만 전설의 용사

ELDORIA 기반의 첫 번째 웹 프로토타입입니다.

## 실행
`index.html` 파일을 브라우저에서 열면 됩니다.

## 포함된 기능
- 10개 직업 선택
- 직업별 기본 능력치 표시
- 능력치마다 기본값 기준 -3~+3 무작위 변동
- 변동량의 합이 0이 되도록 추첨하여 총합 100 유지
- 능력치 다시 뽑기
- 15살 인생 시작 및 브라우저 localStorage 저장

## 아직 구현되지 않은 기능
사건/선택지, 나이 진행, 인생 종료 및 새 인생, 연대기, 이미지, 광고는 다음 개발 단계에서 추가합니다.

## 배포
Cloudflare Pages에 GitHub 저장소를 연결할 경우 프레임워크 없음(None), 빌드 명령 비움, 출력 디렉터리 `/`로 설정하면 되는 정적 사이트입니다.
