# 나 혼자만 전설의 용사 v3

## 배포 파일
- index.html
- style.css
- app.js

기존 Cloudflare Pages / GitHub 저장소에서 위 3개 파일을 덮어쓰고 커밋하면 됩니다.
README.md는 선택 사항입니다.

## v3 변경 사항
- 직업 10개 중 직접 선택
- 선택 직업을 유지한 능력치 새로고침
- 이벤트 선택 후 결과 화면 및 변화량 표시
- 이벤트 / 능력치 탭 분리, 탭 이동 시 진행 상태 유지
- 룸메이트 선택 및 룸메이트 관련 기능 제거

참고: 초기 통합 프로토타입입니다. 일부 이벤트 문구와 모험가·교수 진행 규칙은 추후 플레이테스트를 통해 조정할 수 있습니다.
